# 霓虹竞速 H5

Canvas 2D 俯视角赛车小游戏，支持电脑浏览器和移动浏览器。

## 运行

```bash
npm install
npm run dev
```

然后打开终端显示的本地地址。

## 操作

- 电脑：方向键或 `A / D` 左右移动，空格使用氮气。
- 鼠标：在赛道内左右拖动控制赛车。
- 手机：触摸拖动赛车，点击右下角氮气按钮。
- 点击左下角按钮暂停，暂停后再次点击继续。

## 构建

```bash
npm run typecheck
npm test
npm run build
```

首版使用原创车型和程序绘制素材，进度保存在浏览器本地，不需要登录或后端服务。
